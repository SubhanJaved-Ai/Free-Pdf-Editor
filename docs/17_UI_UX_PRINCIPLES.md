# 17. UI/UX Principles

## Anti-Dashboard
Traditional analytics dashboards force the user to interpret data. Our UI must push the interpretation to the forefront.

## Key UI Elements
1. **The Feed:** The primary interface is a vertically scrolling list of "Alerts" or "Actions", similar to an email inbox or a social feed.
2. **Clarity over Density:** White space is good. Use typography to guide the eye to the monetary impact.
3. **Action Prompts:** Every alert must have clear call-to-action buttons (e.g., "Dismiss", "Mark Resolved").

## Color Palette
- Neutral backgrounds (whites, light grays).
- High contrast typography.
- Semantic colors applied strictly:
  - Red: Profit leaks, immediate danger.
  - Green: Positive anomalies, resolved actions.
  - Blue/Purple: Informational insights.
