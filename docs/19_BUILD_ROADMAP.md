# 19. Build Roadmap

## Phase 1: Foundation
- Initialize Next.js project.
- Configure Tailwind & shadcn/ui.
- Setup Supabase project and database schema.
- Implement Authentication (Login/Signup flow).

## Phase 2: Data Ingestion (Shopify)
- Setup Shopify app credentials.
- Build OAuth flow for merchants to connect their store.
- Implement basic product and order sync endpoints.

## Phase 3: Data Ingestion (Meta Ads)
- Setup Meta app credentials.
- Build Meta OAuth flow.
- Implement cron-based insight syncing.

## Phase 4: Intelligence Engine
- Build the core Rule Engine logic.
- Implement the 3 V1 rules.
- Integrate OpenAI API to generate explanations based on rule triggers.

## Phase 5: UI & Experience
- Build the Alert Feed UI.
- Implement interaction logic (dismissing alerts).
- Final polish and bug fixes.
