# Contributing

Contributions are welcome.

## How to Contribute

1. Open an issue to discuss major changes.
2. Create a separate branch for your changes.
3. Follow the existing code style.
4. Run the available checks before submitting.
5. Submit a pull request for review.

## Project Attribution

Please preserve the existing copyright notices,
LICENSE file, and NOTICE file when redistributing
this project, as required by the applicable license.

Thank you for contributing.
